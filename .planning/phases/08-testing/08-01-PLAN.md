    - initialize: skips /auth/me when no CSRF token exists (getCsrfToken returns null)

    - clearUser: resets user to null, clears permissions, calls csrfManager.clearToken
    - reset: sets status back to 'idle', clears _initializationPromise closure
    - logout: calls apiPost('/auth/logout'), then clearUser
  </behavior>
