Create a new file backend-spring/src/main/java/com/ulticode/common/config/CacheConfig.java with:
- @Configuration and @EnableCaching annotations
- Constructor injection of RedissonClient (same pattern as QueueConfig)
- CacheManager @Bean using RedissonSpringCacheManager or RedisCacheManager with jittered TTL
- TTL formula: baseTtl=300s, jitterRange=30s -> actual TTL = 300 + ThreadLocalRandom.current().nextLong(-30, 31) = 270-330s
- Register cache regions: "problem", "userStats", "contest", "contestRanking" -- all using same config
- Disable cache nullValues
- Use JdkSerializationRedisSerializer (from spring-boot-starter-cache, no extra import needed)

The @EnableCaching goes on CacheConfig, NOT on the main application class.

Example structure:
```java
package com.ulticode.common.config;

import org.springframework.cache.CacheManager;
import org.springframework.cache.annotation.EnableCaching;
import org.springframework.cache.interceptor.KeyGenerator;
import org.springframework.cache.jcache.JCacheCacheManager;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.redisson.api.RedissonClient;
import org.redisson.spring.cache.RedissonSpringCacheManager;

import java.time.Duration;
import java.util.Map;
import java.util.concurrent.ThreadLocalRandom;

@Configuration
@EnableCaching
public class CacheConfig {

    private final RedissonClient redissonClient;

    public CacheConfig(RedissonClient redissonClient) {
        this.redissonClient = redissonClient;
    }

    @Bean
    public CacheManager cacheManager() {
        long baseTtl = 300L;
        long jitterRange = 30L;
        long ttlSeconds = baseTtl + ThreadLocalRandom.current().nextLong(-jitterRange, jitterRange + 1);

        var cacheConfig = new org.redisson.spring.cache.CacheConfig();
        cacheConfig.setTtl(Duration.ofSeconds(ttlSeconds));
        cacheConfig.setCacheNullValues(false);

        Map<String, org.redisson.spring.cache.CacheConfig> configs = Map.of(
                "problem", cacheConfig,
                "userStats", cacheConfig,
                "contest", cacheConfig,
                "contestRanking", cacheConfig
        );

        return new RedissonSpringCacheManager(redissonClient, configs);
    }
}
```

NOTE: If RedissonSpringCacheManager is not available (ClassNotFoundException at compile), fall back to:
```java
import org.springframework.data.redis.cache.RedisCacheManager;
import org.springframework.data.redis.cache.RedisCacheConfiguration;
import org.springframework.data.redis.serializer.JdkSerializationRedisSerializer;

@Bean
public CacheManager cacheManager() {
    long baseTtl = 300L;
    long jitterRange = 30L;
    long ttlSeconds = baseTtl + ThreadLocalRandom.current().nextLong(-jitterRange, jitterRange + 1);

    RedisCacheConfiguration defaultConfig = RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofSeconds(ttlSeconds))
            .serializeValuesWith(RedisSerializationContext.SerializationPair
                    .fromSerializer(new JdkSerializationRedisSerializer()))
            .disableCachingNullValues();

    Map<String, RedisCacheConfiguration> configs = Map.of(
            "problem", defaultConfig,
            "userStats", defaultConfig,
            "contest", defaultConfig,
            "contestRanking", defaultConfig
    );

    return RedisCacheManager.builder(redissonClient.getConnectionFactory())
            .cacheDefaults(defaultConfig)
            .withInitialCacheConfigurations(configs)
            .build();
}
```
