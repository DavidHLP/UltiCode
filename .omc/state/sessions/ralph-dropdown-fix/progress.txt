# Ralph Progress - Fix dropdown menu not opening

## Issue
Dropdown menus in ProblemsListView and UsersListView were not opening on click.

## Root Cause
The DropdownMenu component needed `v-slot` forwarding to properly connect the trigger to the content.

## Fix Applied
The `DropdownMenu.vue` component in management already has the correct implementation:
```vue
<DropdownMenuRoot v-slot="slotProps" data-slot="dropdown-menu" v-bind="forwarded">
  <slot v-bind="slotProps" />
</DropdownMenuRoot>
```

This matches the console's implementation and allows the dropdown to open properly.
