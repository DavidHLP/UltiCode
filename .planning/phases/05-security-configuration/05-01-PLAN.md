    **Step 1: Create CorsProperties.java**

    Create new file `backend-spring/src/main/java/com/ulticode/common/config/CorsProperties.java`:

    ```java
    package com.ulticode.common.config;

    import java.util.List;
    import lombok.Data;
    import org.springframework.boot.context.properties.ConfigurationProperties;
    import org.springframework.stereotype.Component;
    import org.springframework.web.cors.CorsConfiguration;
    import org.springframework.web.cors.CorsConfigurationSource;
    import org.springframework.web.cors.UrlBasedCorsConfigurationSource;

    /**
     * CORS configuration properties.
     * Binds to cors.* properties in application.yml.
     * Origins are externalized via CORS_ALLOWED_ORIGINS environment variable.
     */
    @Data
    @Component
    @ConfigurationProperties(prefix = "cors")
    public class CorsProperties {

        private List<String> allowedOrigins = List.of(
            "http://localhost:9002",
            "http://localhost:9003"
        );

        /**
         * Build a Spring Security CorsConfigurationSource from these properties.
         */
        public CorsConfigurationSource toConfigurationSource() {
            CorsConfiguration config = new CorsConfiguration();
            config.setAllowCredentials(true);
            config.setAllowedOriginPatterns(allowedOrigins);
            config.setAllowedMethods(List.of("GET", "POST", "PUT", "DELETE", "PATCH", "OPTIONS"));
            config.setAllowedHeaders(List.of("*"));
            config.setExposedHeaders(List.of("Authorization", "Set-Cookie", "Content-Disposition", "X-New-CSRF-Token"));
            config.setMaxAge(3600L);

            UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
            source.registerCorsConfiguration("/**", config);
            return source;
        }
    }
    ```

    **Step 2: Modify SecurityConfig.java**

    Add `CorsProperties` injection. The class uses `@RequiredArgsConstructor`, so add a `private final CorsProperties corsProperties;` field. The existing `jwtAuthenticationFilter`, `authenticationEntryPoint`, and `csrfService` fields must remain.

    Replace the entire `corsConfigurationSource()` method body with:
    ```java
    @Bean
    public CorsConfigurationSource corsConfigurationSource() {
        return corsProperties.toConfigurationSource();
    }
    ```

    Remove the unused `java.util.Arrays` and `java.util.Collections` imports that were only used by the old hardcoded CORS config (only if they are not used elsewhere in the file).

    **Step 3: Modify WebSocketProperties.java**

    Change the `allowedOrigins` field to read from the shared `cors.allowed-origins` property:

    Replace:
    ```java
    private String[] allowedOrigins = {"http://localhost:9002", "http://localhost:9003"};
    ```
    With:
    ```java
    @org.springframework.beans.factory.annotation.Value("${cors.allowed-origins:http://localhost:9002,http://localhost:9003}")
    private String[] allowedOrigins = {"http://localhost:9002", "http://localhost:9003"};
    ```

    Note: The `@Value` annotation overrides the field default when the property is present. Spring Boot automatically splits comma-separated values into the String array. WebSocketProperties keeps its own `String[]` type because `WebSocketConfig` calls `setAllowedOriginPatterns(String[])`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client browser -> API (CORS) | Untrusted origins must be rejected; only configured origins allowed |
| Environment variables -> Spring Boot | Ops/infra provides CORS_ALLOWED_ORIGINS; app trusts these blindly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | S (Spoofing) | CORS configuration | mitigate | Origins loaded from env vars, not user input. Production YAML has no insecure fallback. |
| T-05-01-02 | E (Elevation) | CORS misconfiguration | mitigate | `allowCredentials=true` with specific origin patterns (never `*`). `setAllowedOriginPatterns()` used instead of deprecated `setAllowedOrigins()`. |
| T-05-01-03 | I (Information Disclosure) | Empty CORS origins | accept | If CORS_ALLOWED_ORIGINS is empty/unset, Spring Boot uses default dev values from YAML. Production deployment must explicitly set the env var. |
</threat_model>
