# 判题状态的语义边界

> Provenance: project-authored-for-u02。由本项目助手为 U02 学习切片撰写；不是用户作品，也不是授权第三方材料。

`Accepted` 只说明评测器接受了这次运行。它不证明算法最优，也不保证同一思路对所有输入成立。
`Wrong Answer` 说明输出与期望不符，它**不**指出是哪一行代码、哪一个输入导致。
`Runtime Error` 表示**执行阶段的判定失败**，但这个状态的来源**不能仅凭状态本身推断**：用户程序异常退出、评测框架或信封层失败、以及沙箱侧的兜底判定，都可能落到这个状态。要确定来源必须看结构化的执行细节。
超时通常有独立状态（`Time Limit Exceeded`），不能默认等同于 `Runtime Error`；`Memory Limit Exceeded` 与之类似。
把状态当作**已观测事实**使用；把「为什么错/为什么失败」当作**假设**，需要额外证据才能升级为结论。
