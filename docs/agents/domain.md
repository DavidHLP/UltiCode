# Domain docs

## 布局与读取

采用 single-context，根目录 GLOSSARY.md 是统一领域词汇表。

- 领域建模与架构探索前读取 GLOSSARY.md 的相关术语。
- 通过 docs/index.md 定位当前主题文档。
- 架构边界与决策说明归入 docs/ARCHITECTURE.md；保留源码及迁移注释中的局部设计理由。
- 沿用现有文档结构，不新建 docs/adr/ 或分域词汇表。
- 缺少某个术语不阻塞工作；仅在实际澄清概念时补充。

## 使用约定

事项、设计和代码讨论使用词汇表中的领域名称。
发现术语或设计冲突时明确指出，并以当前源码、配置及适用契约核实，不静默覆盖既有决定。
