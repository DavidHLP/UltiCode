<objective>
Remove weak default password fallbacks from docker-compose.yml and ensure all credentials are injected via required environment variables.

Purpose: The current docker-compose.yml has `:-ulticode`, `:-ulticode_redis`, and `:-root` fallback values that serve as weak default passwords. Anyone with access to the repository can see these defaults, and if a developer forgets to set the env vars, the services start with known credentials. Removing these defaults ensures Docker Compose fails loudly if credentials are not configured.

Output: Modified docker-compose.yml with required env vars and updated .env.example with clearer documentation.
</objective>
