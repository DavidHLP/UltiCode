# 判题状态的语义边界

> Provenance: project-authored-for-u02。由本项目助手为 U02 学习切片撰写；不是用户作品，也不是授权第三方材料。

`Accepted` 只说明评测器接受了这次运行。它不证明算法最优，也不保证同一思路对所有输入成立。
`Wrong Answer` 说明输出与期望不符，它**不**指出是哪一行代码、哪一个输入导致。
`Runtime Error` 是结果分类的**兜底分支**：只有当一次执行未落入任何已识别的信号时才得到这个状态。已识别的信号各有独立状态，包括容器创建被拒、沙箱侧 fork/pids 资源耗尽、OCI runtime 错误与编译失败。
因此 `Runtime Error` **不指向任何具体原因**——它既不等于用户程序异常退出，也不等于超时，更不能据此推断评测框架或信封层的失败。要确定来源必须查看该次运行的结构化执行细节。
超时通常有独立状态（`Time Limit Exceeded`），`Memory Limit Exceeded` 与之类似。
把状态当作**已观测事实**使用；把「为什么错/为什么落到这个状态」当作**假设**，需要额外证据才能升级为结论。
