  <action>
Per D-06 (calculate from moderation_queue using SQL TIMESTAMPDIFF):

**Part A: Add aggregation query to ModerationQueueMapper**

Add the following method to ModerationQueueMapper.java (after the existing @Select methods):

```java
@Select("SELECT COALESCE(AVG(TIMESTAMPDIFF(HOUR, created_at, resolved_at)), 0) "
    + "FROM moderation_queue "
    + "WHERE status = 'RESOLVED' AND resolved_at IS NOT NULL")
double avgResolutionTimeHours();
```

Key design decisions:
- `COALESCE(..., 0)` handles the empty result case -- AVG returns NULL when no rows match, which would cause NPE when unboxing to double (Pitfall 6 from RESEARCH.md)
- `WHERE resolved_at IS NOT NULL` is a safety filter (Assumption A2 from RESEARCH.md)
- `TIMESTAMPDIFF(HOUR, ...)` gives resolution time in hours directly
