# 判题状态的语义边界

> Provenance: project-authored-for-u02。由本项目助手为 U02 学习切片撰写；不是用户作品，也不是授权第三方材料。

`Accepted` 只说明评测器接受了这次运行。它不证明算法最优，也不保证同一思路对所有输入成立。
`Wrong Answer` 说明输出与期望不符，它**不**指出是哪一行代码、哪一个输入导致。
`Runtime Error` 表示执行阶段失败，常见原因是程序异常退出或超时；它与「答案错误」是不同类别，不能互相替代。
`Time Limit Exceeded` 与 `Memory Limit Exceeded` 属于资源边界，不是逻辑错误。
把状态当作**已观测事实**使用；把「为什么错」当作**假设**，并且需要额外证据才能升级为结论。
