## Milestone Summary

**Key Decisions:**

- Decision: springdoc 2.6.0 retained (Rationale: 2.8.17 incompatible with Spring Boot 3.2.5)
- Decision: Storage key `ulticode-locale` (Rationale: Consistent locale preference key across frontends)
- Decision: Non-active locale via dynamic import() (Rationale: Reduce initial bundle size)
- Decision: missingWarn: import.meta.env.DEV (Rationale: Suppress warnings in prod only)

**Issues Resolved:**

- MyBatis result mapping failure with immutable `ProblemTagDTO` record (500 error in /admin/problems)
- Management had no way to switch language — LanguageSwitcher added to Console header
- vue-i18n version mismatch between Console (11.3.2) and Management (10.0.8)

**Issues Deferred:**

- springdoc 3.x upgrade (requires Spring Boot 4.0 + Java 21)
- Japanese translations (not in v3.0 scope)
- Backend content i18n (database i18n out of scope)

**Technical Debt Incurred:**

- Management TypeScript type error in i18n/utils.ts (pre-existing, not introduced in v3.0)
