# Milestone v1.6: User & Social

**Status:** ✅ SHIPPED 2026-04-21
**Phases:** 26-29
**Total Plans:** 5

## Overview

v1.6 delivered the social layer for UltiCode — follow system, user profiles, achievement backend with WebSocket notifications, and social frontend. Users can now follow each other, view profiles at `/profile/{username}`, and earn achievements with real-time notifications.

## Phases

### Phase 26: Follow System

**Goal:** Users can follow/unfollow each other and view follower/following lists
**Depends on:** None (first phase)
**Requirements:** FOLLOW-01, FOLLOW-02, FOLLOW-04
**Plans:** 1 plan

Plans:

- [x] 26-01: Follow system implementation (entity, mapper, service, controller)

**Details:**
- UserFollow entity with composite key (followerId, followingId)
- FollowMapper with idempotent insert (ON DUPLICATE KEY UPDATE), paginated lists
- FollowService with self-follow prevention, @Async achievement triggers
- FollowController: POST/DELETE /users/{id}/follow, GET /users/{id}/followers, GET /users/{id}/following
- AchievementType.FOLLOWER_COUNT and onFollowCountUpdated() trigger

### Phase 27: Profile Backend

**Goal:** Users can view and edit user profiles with social stats
**Depends on:** Phase 26
**Requirements:** PROFILE-01, PROFILE-03
**Plans:** 1 plan

Plans:

- [x] 27-01: User profile endpoint, profile edit, avatar upload

**Details:**
- User profile endpoint returning username, avatar, bio, social stats, achievements
- Profile edit via PUT /users/me/profile
- Avatar upload endpoint

### Phase 28: Achievement Backend

**Goal:** Achievement system is complete with triggers, progress tracking, categories, and real-time notifications
**Depends on:** Phase 26, Phase 27
**Requirements:** ACHV-01, ACHV-02, ACHV-03, ACHV-04
**Plans:** 1 plan

Plans:

- [x] 28-01: Achievement triggers, progress indicators, categories, WebSocket notifications

**Details:**
- Automatic achievement awards on criteria (first problem, language milestones, follower milestones, streaks, contests)
- Progress tracking via GET /users/me/achievements/progress
- Category filtering via GET /achievements?category={category}
- WebSocket notification on achievement earn

### Phase 29: Social Frontend

**Goal:** Profile page and social features visible and interactive in Console
**Depends on:** Phase 26, Phase 27, Phase 28
**Requirements:** PROFILE-02, FOLLOW-03
**Plans:** 2 plans

Plans:

- [x] 29-01: Backend API endpoints and frontend API/composable layer
- [x] 29-02: Profile page and follow button UI components

**Details:**

## Milestone Summary

**Key Decisions:**
- ON DUPLICATE KEY UPDATE for idempotent follow (no duplicate errors)
- @Async achievement triggers prevent blocking follow response
- Follow status uses existing FollowMapper.exists() — no new mapper method
- AchievementController GET /user/{id} placed before /user/me to avoid path conflict

**Issues Resolved:**
- V26 migration versioning conflict (V26 < V99 existing) — renamed to V100
- Flyway schema history inconsistency — repaired via manual rank deletion/insert

**Technical Debt Incurred:**
- None significant — all social features delivered as scoped
