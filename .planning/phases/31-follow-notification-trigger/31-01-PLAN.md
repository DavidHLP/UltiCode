# Phase 31-01: Follow Notification Trigger

## Context

Add follow notification trigger to `FollowServiceImpl.follow()`. When User A follows User B, User B receives an in-app notification persisted to DB and pushed via WebSocket. Depends on Phase 30 (WebSocket push wiring).

## Key Decisions

- **D-01:** Call `notificationService.createNotification()` from `FollowServiceImpl.follow()` after successful follow
- **D-02:** Sync call (not @Async) — createNotification() handles persist + WebSocket push
- **D-03:** No notification on unfollow
- **D-04:** type = "FOLLOW" (from NotificationType enum)
- **D-05:** category = "social"
- **D-06:** title = "{username} followed you"
- **D-07:** body = "" (empty)
- **D-08:** link = "/profile/{followerUsername}"
- **D-09:** metadata includes: followerUsername, followerAvatar
- **D-10:** Notify only on first follow (idempotent)
- **D-12:** FollowServiceImpl needs NotificationService injected
- **D-13:** Notification failure is caught and logged — follow succeeds regardless

## NotificationService.createNotification() Signature

```java
NotificationVO createNotification(String userId, String type, String category,
                                 String title, String body, String link)
```

Returns `NotificationVO`. Throws on error (caller must catch).

## Acceptance Criteria

1. When User A follows User B for the first time, User B receives a notification with:
   - type = "FOLLOW"
   - category = "social"
   - title = "{UserA_username} followed you"
   - body = ""
   - link = "/profile/{UserA_username}"
   - metadata contains: followerUsername (UserA's username), followerAvatar (UserA's avatar URL)
2. When User A follows User B again (already following), NO notification is sent
3. When User A unfollows User B, NO notification is sent
4. If notification creation fails, the follow action still succeeds
5. The notification is persisted to the database AND pushed via WebSocket (handled by NotificationService.createNotification())
6. Unit test verifies all three scenarios: first follow notifies, re-follow does not notify, notification failure does not break follow
