<task type="auto">
  <name>Task 2: Create AchievementCheckListener with @Async + @TransactionalEventListener(AFTER_COMMIT)</name>
  <files>backend-spring/src/main/java/com/ulticode/modules/achievement/listener/AchievementCheckListener.java</files>
  <action>
Create a new listener service at `backend-spring/src/main/java/com/ulticode/modules/achievement/listener/AchievementCheckListener.java`.

This listener runs after the main transaction commits, calls checkAndAwardAchievements (which is @Transactional), and publishes AchievementEarnedEvent on success. Per D-06: failures log.warn and silently fail (no retry).

Follow the same pattern as AchievementNotificationListener for @Async + @RequiredArgsConstructor.

```java
package com.ulticode.modules.achievement.listener;

import com.ulticode.modules.achievement.constants.AchievementType;
import com.ulticode.modules.achievement.event.AchievementCheckEvent;
import com.ulticode.modules.achievement.service.AchievementTriggerService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;
import org.springframework.transaction.event.TransactionPhase;
import org.springframework.transaction.event.TransactionalEventListener;

@Slf4j
@Service
@RequiredArgsConstructor
public class AchievementCheckListener {

    private final AchievementTriggerService achievementTriggerService;

    @Async
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onAchievementCheck(AchievementCheckEvent event) {
        try {
            achievementTriggerService.checkAndAwardAchievements(
                event.userId(),
                event.type(),
                event.currentValue()
            );
        } catch (Exception e) {
            log.warn("Failed to check/award achievements for user {} type {}: {}",
                event.userId(), event.type(), e.getMessage());
        }
    }
}
```

Each trigger method should:
- Be annotated with @Async
- Return void
- Publish AchievementCheckEvent instead of calling checkAndAwardAchievements

Example pattern for onProblemSolved:
```java
@Override
@Async
public void onProblemSolved(String userId, int problemsSolvedCount) {
    eventPublisher.publishEvent(new AchievementCheckEvent(userId, AchievementType.PROBLEMS_SOLVED, problemsSolvedCount));
}
```

Apply the same pattern to ALL trigger methods. The @Async annotation on the trigger method (not on the event listener) is what makes the call non-blocking from the caller's perspective.

Note: checkAndAwardAchievements stays @Transactional and is now called only by AchievementCheckListener after commit.
