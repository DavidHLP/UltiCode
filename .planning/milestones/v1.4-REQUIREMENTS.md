## v1.4 Requirements

### Solutions

- [ ] **SOL-01**: Solutions — 每题至少 1 篇，中等难度 2-3 篇，目标 ~100 篇，覆盖所有 32 道题
- [ ] **SOL-02**: Solution 内容包含中文注释、Markdown 格式、代码块
- [ ] **SOL-03**: 所有 FK 引用有效（user_id, problem_id）

### Submissions

- [ ] **SUB-01**: Submissions — 增加 WA/TLE/MLE/RE 等非 AC 结果，目标 ~200 条额外记录
- [ ] **SUB-02**: Status 分布：AC 45-55%, WA 20-30%, TLE 8-12%, RE 5-10%, MLE 3-5%, CE 2-5%
- [ ] **SUB-03**: 修复 V17 ` Accepted` 前导空格 bug（所有 status 值必须精确匹配 submission_statuses 表）
- [ ] **SUB-04**: 所有 FK 引用有效（user_id, problem_id）

### Collections

- [ ] **COL-01**: Collections — 场景化（难度/标签/公司），目标 ~50 个
- [ ] **COL-02**: 每个 Collection 至少 3 个 item
- [ ] **COL-03**: Collections 包含 icon 和 color（Lucide names + Tailwind colors）
- [ ] **COL-04**: Collection_items FK 引用有效的 problem_lists（来自 V15）

## Future Requirements

- Solution comments 扩展（随 solution 增长）
- Contest-related collections（独立领域）
- Problem 扩充至 100-200 道题

## Out of Scope

- Forum 数据扩充
- Recommendation service 改动
