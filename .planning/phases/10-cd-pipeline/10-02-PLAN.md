<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VPS -> GHCR | VPS pulls images from GHCR; requires docker login with valid credentials |
| IMAGE_TAG injection | IMAGE_TAG set by deploy workflow; if incorrect, wrong images run on VPS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05 | Tampering | IMAGE_TAG points to malicious image | mitigate | Deploy workflow only uses SHA tags from docker-publish.yml output or 'latest'; GHCR registry scoped to repository |
| T-10-06 | Information Disclosure | DB_PASSWORD in compose env vars | accept | Compose file uses variable interpolation; actual values come from VPS environment or deploy secrets, not hardcoded |
| T-10-07 | Tampering | GHCR image overwritten | accept | GHCR images only pushable by docker-publish.yml on main branch; `latest` tag always latest main commit |
</threat_model>
