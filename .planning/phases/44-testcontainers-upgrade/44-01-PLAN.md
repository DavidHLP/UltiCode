## Task 2: Check for API breaking changes

**Action:** Research breaking changes between testcontainers 1.11.3 and 11.x.

### Known Breaking Changes to Verify

1. **GenericContainer.getFirstMappedPort()** — Deprecated/removed in 11.x
   - 1.11.3: `container.getFirstMappedPort()` (returns first exposed port)
   - 11.x: Use `container.getMappedPort(6379)` instead (explicit port number)

2. **@Container annotation** — Should be compatible, verify no changes

3. **@Testcontainers annotation** — Should be compatible, verify no changes

4. **@DynamicPropertySource** — Standard Spring Boot annotation, no changes

**Acceptance Criteria:**
- Document any breaking API changes found
- If `getFirstMappedPort()` is removed, update RateLimitIntegrationTest.java
