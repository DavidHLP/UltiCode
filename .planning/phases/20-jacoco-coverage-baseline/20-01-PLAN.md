<task type="auto">
  <name>Task 1: Add JaCoCo plugin to pom.xml with coverage enforcement</name>
  <files>backend-spring/pom.xml</files>
  <action>
Add the jacoco-maven-plugin to backend-spring/pom.xml inside the &lt;build>&lt;plugins> section. The plugin must:
1. Bind to the `verify` lifecycle (not `test`) — per D-08
2. Enforce line coverage minimum at 50% — per D-01
3. Enforce branch coverage minimum at 40% — per D-02
4. Use &lt;rules> with &lt;fail> elements to halt build on violation

Plugin configuration structure:
```xml
&lt;plugin>
  &lt;groupId>org.jacoco&lt;/groupId>
  &lt;artifactId>jacoco-maven-plugin&lt;/artifactId>
  &lt;version>0.8.11&lt;/version>
  &lt;executions>
    &lt;execution>
      &lt;id>prepare-agent&lt;/id>
      &lt;goals>&lt;goal>prepare-agent&lt;/goal>&lt;/goals>
    &lt;/execution>
    &lt;execution>
      &lt;id>report&lt;/id>
      &lt;phase>test&lt;/phase>
      &lt;goals>&lt;goal>report&lt;/goal>&lt;/goals>
    &lt;/execution>
    &lt;execution>
      &lt;id>check&lt;/id>
      &lt;goals>&lt;goal>check&lt;/goal>&lt;/goals>
      &lt;configuration>
        &lt;rules>
          &lt;rule>
            &lt;element>BUNDLE&lt;/element>
            &lt;limits>
              &lt;limit>
                &lt;counter>LINE&lt;/counter>
                &lt;value>COVEREDRATIO&lt;/value>
                &lt;minimum>0.50&lt;/minimum>
              &lt;/limit>
              &lt;limit>
                &lt;counter>BRANCH&lt;/counter>
                &lt;value>COVEREDRATIO&lt;/value>
                &lt;minimum>0.40&lt;/minimum>
              &lt;/limit>
            &lt;/limits>
          &lt;/rule>
        &lt;/rules>
      &lt;/configuration>
    &lt;/execution>
  &lt;/executions>
&lt;/plugin>
```

**Important:** Place this plugin BEFORE the maven-surefire-plugin in the &lt;plugins> list so that JaCoCo's prepare-agent goal runs first and instruments the JVM for test coverage. The surefire plugin should NOT be reordered — keep existing surefire and failsafe configuration intact.
</action>
  <verify>
    <automated>cd backend-spring && ./mvnw help:effective-pom -Dplugin=org.jacoco:jacoco-maven-plugin 2>&1 | grep -c "jacoco-maven-plugin" && echo "JaCoCo plugin confirmed in effective POM"</automated>
  </verify>
  <done>jacoco-maven-plugin present in effective POM with line 50% and branch 40% limits</done>
</task>

<task type="auto">

  <files>backend-spring/pom.xml</files>
  <action>
Add &lt;excludes> configuration to the JaCoCo check rule to exclude generated and infrastructure classes. Add this inside the &lt;rule> element, after &lt;limits>:

```xml

  &lt;exclude>**/*Mapper.java&lt;/exclude>
  &lt;exclude>**/*MapperImpl.java&lt;/exclude>
  &lt;exclude>**/entity/*.java&lt;/exclude>
  &lt;exclude>**/dto/*.java&lt;/exclude>
  &lt;exclude>**/*DTO.java&lt;/exclude>
  &lt;exclude>**/*VO.java&lt;/exclude>
  &lt;exclude>**/*BO.java&lt;/exclude>
  &lt;exclude>**/config/*Config.java&lt;/exclude>
  &lt;exclude>**/*Config.java&lt;/exclude>
  &lt;exclude>**/*Properties.java&lt;/exclude>
  &lt;exclude>**/constant/*.java&lt;/exclude>
  &lt;exclude>**/*Application.java&lt;/exclude>
&lt;/excludes>
```

This satisfies D-03 (generated mappers), D-04 (entities), D-05 (DTOs/VO), D-06 (config classes), and D-07 (pom.xml).
</action>
