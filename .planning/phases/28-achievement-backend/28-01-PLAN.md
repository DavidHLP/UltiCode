## Task 4: Create AchievementNotificationListener (async WebSocket listener)

- read_first:
    - `backend-spring/src/main/java/com/ulticode/websocket/NotificationService.java`
    - `backend-spring/src/main/java/com/ulticode/modules/achievement/event/AchievementEarnedEvent.java`
    - `backend-spring/src/main/java/com/ulticode/modules/websocket/notification/dto/BadgeEarnedPayload.java`
- action: |
    Create new file `backend-spring/src/main/java/com/ulticode/modules/achievement/listener/AchievementNotificationListener.java`:
    ```java
    package com.ulticode.modules.achievement.listener;

    import com.ulticode.modules.achievement.event.AchievementEarnedEvent;
    import com.ulticode.modules.websocket.notification.dto.BadgeEarnedPayload;
    import com.ulticode.websocket.NotificationService;
    import lombok.RequiredArgsConstructor;
    import lombok.extern.slf4j.Slf4j;
    import org.springframework.context.event.EventListener;
    import org.springframework.scheduling.annotation.Async;
    import org.springframework.stereotype.Service;

    @Slf4j
    @Service
    @RequiredArgsConstructor
    public class AchievementNotificationListener {

        private final NotificationService notificationService;

        @Async
        @EventListener
        public void onAchievementEarned(AchievementEarnedEvent event) {
            log.info("Achievement earned: user={} achievement={}", event.userId(), event.achievementKey());
            BadgeEarnedPayload payload = BadgeEarnedPayload.of(
                event.achievementName(),
                event.achievementDescription(),
                event.achievementIcon(),
                event.achievementTier(),
                event.points()
            );
            notificationService.sendBadgeEarned(event.userId(), payload.toMap());
        }
    }
    ```
- verify: test -f AchievementNotificationListener.java && grep "@Async|@EventListener|sendBadgeEarned" AchievementNotificationListener.java
- acceptance_criteria:
    - File exists at correct path
    - Class annotated @Service
    - Method annotated @Async and @EventListener
    - Method calls notificationService.sendBadgeEarned()
    - Backend compiles without error
