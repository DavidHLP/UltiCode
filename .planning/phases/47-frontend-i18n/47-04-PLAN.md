# Phase 47-04: LanguageSwitcher UI for Management Frontend

## Context

Phase 47-02 implemented `useLocale()` composable for Management. Phase 47-03 UAT revealed that while the composable works, users have **no UI to trigger locale switching** — there is no `LanguageSwitcher` component in Management.

Console already has a working `LanguageSwitcher.vue` at `console/src/components/LanguageSwitcher.vue` using the same `useLocale` composable pattern. Management needs the same.

**UAT finding**: `<html lang="">` is empty in Management because `useLocale` is not called on init. The switcher component must call `setLocale()` once to initialize `document.documentElement.lang`.

<acceptance_criteria>
- [ ] `grep -r "document.documentElement.lang" management/src` finds the assignment in `useLocale.ts`
- [ ] `grep "useLocale\|setLocale" management/src/main.ts` confirms the composable is called at startup, OR the first `LanguageSwitcher` render triggers it
- [ ] `document.documentElement.lang` is set before any user interaction (verified by loading the page and checking `<html lang="">` in DevTools)
</acceptance_criteria>

<action>
Inspect `management/src/main.ts`. If `useLocale` / `setLocale` is not called there, add a startup initialization call:

```ts
// management/src/main.ts — near the top after i18n is installed
import { setLocale } from "@/i18n";

// Initialize locale from stored preference on app startup
// This ensures document.documentElement.lang is set even before any component mounts
const storedLocale = localStorage.getItem('ulticode-locale') as 'zh-CN' | 'en-US' | null;
if (storedLocale === 'zh-CN' || storedLocale === 'en-US') {
  setLocale(storedLocale);
} else {
  // Detect browser preference
  const browserLang = navigator.language;
  if (browserLang.startsWith('zh')) {
    setLocale('zh-CN');
  } else {
    setLocale('en-US');
  }
}
```

This mirrors what Console does via `i18n/index.ts`'s `getInitialLocale()` + `setLocale()`. The key is that `document.documentElement.lang` gets written on the very first paint, not on first user interaction.
</action>
