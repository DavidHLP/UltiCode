## Exports

## Implementation Details

### Request Interceptor
- Attaches `X-CSRF-Token` header for non-GET/HEAD/OPTIONS methods
- Uses `csrfManager.getToken()` to get current token

### Response Interceptor
- Checks for `x-new-csrf-token` response header (axios lowercases headers)
- Calls `csrfManager.refreshFromResponse({ csrfToken: newToken })`

### Error Interceptor
- Detects 403 CSRF errors via `error.response.status === 403` and `message.includes("CSRF")` or `code === 40300`
- Uses request-level `config._metadata.csrfRetried` flag (no global state)
- Fetches new token via GET /auth/me
- Retries once, then propagates error
