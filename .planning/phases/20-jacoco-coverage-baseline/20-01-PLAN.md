<task type="auto">
  <name>Task 1: Add JaCoCo Maven plugin with coverage enforcement</name>
  <files>backend-spring/pom.xml</files>
  <action>
Add the following configuration to backend-spring/pom.xml inside the &lt;build&gt;&lt;plugins&gt; section:

```xml
<plugin>
  <groupId>org.jacoco</groupId>
  <artifactId>jacoco-maven-plugin</artifactId>
  <version>0.8.12</version>
  <executions>
    <execution>
      <id>prepare-agent</id>
      <goals>
        <goal>prepare-agent</goal>
      </goals>
    </execution>
    <execution>
      <id>check</id>
      <goals>
        <goal>check</goal>
      </goals>
      <configuration>
        <rules>
          <rule>
            <element>BUNDLE</element>
            <limits>
              <limit>
                <counter>LINE</counter>
                <value>COVEREDRATIO</value>
                <minimum>0.50</minimum>
              </limit>
              <limit>
                <counter>BRANCH</counter>
                <value>COVEREDRATIO</value>
                <minimum>0.40</minimum>
              </limit>
            </limits>
          </rule>
        </rules>
      </configuration>
    </execution>
    <execution>
      <id>report</id>
      <goals>
        <goal>report</goal>
      </goals>
    </execution>
  </executions>
</plugin>
```

This binds the jacoco:check goal to the verify lifecycle phase, enforcing 50% line / 40% branch coverage. The build will FAIL (not warn) when thresholds are not met because JaCoCo's check goal returns a non-zero exit code on failure.
  </action>
  <verify>
cd backend-spring && ./mvnw help:effective-pom -Dplugin=org.jacoco:jacoco-maven-plugin 2>/dev/null | grep -A5 jacoco-maven-plugin
  </verify>
  <done>jacoco-maven-plugin version 0.8.12 configured with LINE 0.50 and BRANCH 0.40 limits in pom.xml</done>
</task>

<task type="auto">
  <name>Task 2: Configure exclusion patterns for generated code</name>
  <files>backend-spring/pom.xml</files>
  <action>
Add an &lt;excludes&gt; configuration inside the &lt;configuration&gt; block of the jacoco-maven-plugin check execution:

```xml
<configuration>
  <excludes>
    <exclude>**/*Mapper.java</exclude>
    <exclude>**/*Mapper.xml</exclude>
    <exclude>**/entity/*.java</exclude>
    <exclude>**/*DTO.java</exclude>
    <exclude>**/*VO.java</exclude>
    <exclude>**/*BO.java</exclude>
    <exclude>**/*Response.java</exclude>
    <exclude>**/*Request.java</exclude>
    <exclude>**/*Config.java</exclude>
    <exclude>**/*Properties.java</exclude>
    <exclude>**/*Application.java</exclude>
  </excludes>
  <rules>
    <rule>
      <element>BUNDLE</element>
      <limits>
        <limit>
          <counter>LINE</counter>
          <value>COVEREDRATIO</value>
          <minimum>0.50</minimum>
        </limit>
        <limit>
          <counter>BRANCH</counter>
          <value>COVEREDRATIO</value>
          <minimum>0.40</minimum>
        </limit>
      </limits>
    </rule>
  </rules>
</configuration>
```

Place this &lt;configuration&gt; inside the &lt;check&gt; execution block, alongside the rules element already added in Task 1.
  </action>
  <verify>
grep -A20 "jacoco-maven-plugin" backend-spring/pom.xml | grep -c "exclude"
  </verify>
  <done>Generated mapper, entity, DTO, and config classes excluded from coverage</done>
</task>
