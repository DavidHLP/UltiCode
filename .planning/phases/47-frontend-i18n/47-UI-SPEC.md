## Language Switcher UI

### Component: `LanguageSwitcher.vue`

**Location:** `console/src/components/LanguageSwitcher.vue` (already exists)

**Implementation:** Dropdown menu via shadcn-vue `DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuItem`.

**Decision D-10 resolution:** Dropdown — already implemented in the existing `LanguageSwitcher.vue`. The dropdown is the right choice for the Console header because:
- Header space is constrained; a segmented control would crowd the header
- Language switch is an occasional action, not a primary toggle
- Dropdown pattern is universally recognized for language selection

### Visual Spec

**Trigger:**
- `Button variant="ghost"` size `icon` — `h-8 w-8`
- Icon: `IconGlobe` (Lucide `globe`) at `h-4 w-4`
- Icon color: `text-muted-foreground` → `hover:text-foreground`
- Hover background: `hover:bg-accent/50`
- Transition: `transition-colors`

**Dropdown Content:**
- `min-w-40` (minimum width 160px)
- Padding: `p-1.5`
- Animation: `animate-in fade-in-0 zoom-in-95 duration-200`
- Alignment: `align="end"` (opens to the left, anchored to right edge of trigger)

**Dropdown Item (per locale):**
- Flex layout: `flex items-center justify-between`
- Padding: `px-3 py-2`
- Transition: `transition-all duration-200`

**Active locale item:**
- Background: `bg-accent/50`
- Text color: `text-accent-foreground`
- Font weight: `font-bold`

**Inactive locale item:**
- Background on hover: `hover:bg-accent/30`

**Item content (left side):**
- Flag emoji + native language name
- Layout: `flex items-center gap-3`
- Flag: `text-base leading-none`
- Native name: `text-[11px] uppercase tracking-widest font-data`

**Checkmark (right side, active only):**
- Lucide `Check` icon at `size-3.5` (14px)
- Color: `text-[var(--accent-primary)]`
- Animation: `animate-in zoom-in-50 duration-300`

**Keyboard accessibility:**
- `aria-label` via `$t("common.actions.toggleLanguage")` on trigger
- `sr-only` screen-reader text on trigger button
- Full keyboard navigation via Radix Vue `DropdownMenu`

**Screen reader:**
- Trigger button has `sr-only` text: `$t("common.actions.toggleLanguage")`

## Copywriting Contract

| Element | Key | Copy (en-US) | Copy (zh-CN) |
|---------|-----|--------------|--------------|
| Screen reader label | `common.actions.toggleLanguage` | "Toggle language" | "切换语言" |
| zh-CN native name | LOCALE_CONFIGS["zh-CN"].nativeName | "简体中文" | — |
| en-US native name | LOCALE_CONFIGS["en-US"].nativeName | "English" | — |
| Storage fallback toast | `storage.ts` getLocalizedMessage | "Language preference will not persist after closing browser" | "语言偏好设置将在关闭浏览器后不会保存" |

**Locale native names** (from `console/src/i18n/types.ts` LOCALE_CONFIGS):
- zh-CN: `简体中文` (Chinese Simplified)
- en-US: `English`

**Flag emojis** (from LOCALE_CONFIGS):
- zh-CN: `🇨🇳`
- en-US: `🇺🇸`

**Storage fallback messages** (from `console/src/i18n/utils/storage.ts`):
- localStorage failed: "Language preference will not persist after closing browser" / "语言偏好设置将在关闭浏览器后不会保存"
- sessionStorage fallback: "Language preference will persist during this session only" / "语言偏好设置仅在此会话期间保持"
- memoryStorage fallback: "Language preference set for current page only" / "语言偏好设置仅在当前页面有效"

**Primary CTA:** Not applicable — no CTA in language switcher, it is a toggle/dropdown.

**Empty state:** Not applicable — the switcher always shows two locales.

**Error state:** Not applicable — the switcher falls back gracefully via `storage.ts` fallback chain (localStorage → sessionStorage → memory).

**Destructive confirmation:** None — language switching is non-destructive.
