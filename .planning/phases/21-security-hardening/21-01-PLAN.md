## Wave 1: Security Hardening Fixes

### Task 1: SEC-02 — Admin Forum commentCount sort with real COUNT query

**requirements:** [SEC-02]

**action:**
AdminForumServiceImpl.java 第92-96行，commentCount 排序默认使用 createdAt。需要改为实际查询 forum_comments 表的 COUNT。

方案：在 enrich 之后，对结果按 commentCount 进行内存排序：

```java
// 在返回前，按 commentCount 排序
List<AdminForumPostVO> sortedVos = vos.stream()
    .sorted((a, b) -> isAsc ?
        Integer.compare(a.getCommentCount() != null ? a.getCommentCount() : 0,
                       b.getCommentCount() != null ? b.getCommentCount() : 0) :
        Integer.compare(b.getCommentCount() != null ? b.getCommentCount() : 0,
                       a.getCommentCount() != null ? a.getCommentCount() : 0))
    .collect(Collectors.toList());
```

**read_first:**
- `backend-spring/src/main/java/com/ulticode/modules/admin/service/impl/AdminForumServiceImpl.java`
- `backend-spring/src/main/java/com/ulticode/modules/admin/dto/AdminForumPostVO.java`

**acceptance_criteria:**
- grep "commentCount" AdminForumServiceImpl.java — 排序逻辑使用实际 commentCount 值
- grep "sorted" AdminForumServiceImpl.java — 包含流式排序
