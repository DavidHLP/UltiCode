**FollowServiceImpl** (`backend-spring/src/main/java/com/ulticode/modules/follow/service/impl/FollowServiceImpl.java`):
- Package: `com.ulticode.modules.follow.service.impl`
- `@Slf4j`, `@Service`, `@RequiredArgsConstructor`
- Dependencies: `FollowMapper`, `UserMapper`, `AchievementTriggerService`, `ApplicationEventPublisher`

**follow() method logic**:
1. If currentUserId equals targetUserId, throw BusinessException(ErrorCode.FORBIDDEN, "Cannot follow yourself")
2. Check if target user exists via UserMapper.selectById(targetUserId) - throw BusinessException(ErrorCode.USER_NOT_FOUND) if null
3. Check if already following via FollowMapper.exists(currentUserId, targetUserId)
4. If not following, call FollowMapper.insertIdempotent(currentUserId, targetUserId)
5. Get updated stats via getFollowStats(targetUserId)
6. Call onFollowCountUpdated(currentUserId, stats.getFollowingCount()) on achievementTriggerService (ASYNC)
7. Call onFollowCountUpdated(targetUserId, stats.getFollowerCount()) on achievementTriggerService (ASYNC)
8. Return FollowStatsDTO

**unfollow() method logic**:
1. Check if target user exists
2. Call FollowMapper.delete(currentUserId, targetUserId) - no error if not following (idempotent)
3. Get updated stats and call achievement triggers same as follow
4. Return FollowStatsDTO

**getFollowers() method logic**:
1. Create Page<UserFollow> with offset pagination (page, pageSize)
2. Call FollowMapper.selectByFollowingId(followerId, page, pageSize)
3. Get total count
4. Batch fetch users via UserMapper.selectBatchIds(...)
5. Map to UserSummaryDTO list
6. Return PageResult.of(list, total, page, pageSize)

**getFollowing() method logic**:
1. Same pattern as getFollowers but using selectByFollowerId

**getFollowStats() method logic**:
1. Call FollowMapper.countByFollowerId and countByFollowingId
2. Return FollowStatsDTO

IMPORTANT: Use @Async for achievement trigger calls. The service should NOT block on achievement checks. Inject AchievementTriggerService and call the trigger methods directly - the @Async annotation on the implementation method handles async execution.

**Async configuration**: The project already has @EnableAsync configured (per Phase 28 research notes). The achievementTriggerService.onFollowCountUpdated() method should be annotated with @Async. If not found, add @Async to the trigger call in FollowServiceImpl directly.
