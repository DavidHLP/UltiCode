## Critical Version Decision

**springdoc 2.8.17 is INCOMPATIBLE with Spring Boot 3.2.5.**
- springdoc 2.8.17 uses Spring Boot 3.5.13 as parent POM
- Project uses Spring Boot 3.2.5
- No version of springdoc 2.8.x supports Spring Boot 3.2.5
- Only springdoc 2.5.x and 2.6.x are compatible
- **Decision: Stay on 2.6.0** (swagger-ui 5.17.14, compatible)

## Annotation Template (from AchievementController.java)

Every annotated method follows this pattern:

```java
@Operation(summary = "Get achievement by ID")
@ApiResponse(responseCode = "404", description = "Achievement not found")
@GetMapping("/{id}")
public Result<AchievementVO> getById(@PathVariable String id) {
    return Result.success(achievementService.getById(id));
}
```

For paginated responses:
```java
@Operation(summary = "List achievements")
@ApiResponse(responseCode = "200", description = "Achievements retrieved",
    content = @Content(schema = @Schema(implementation = PageResult.class)))

```

For void returns:
```java
@Operation(summary = "Delete achievement")
@ApiResponse(responseCode = "200", description = "Achievement deleted")
@ApiResponse(responseCode = "404", description = "Achievement not found")
@DeleteMapping("/{id}")

```

## What To Annotate

For each non-void return method, add @ApiResponse for:
1. responseCode = "200" (success) with content schema pointing to inner Result<T> type
2. responseCode = "401" (unauthorized) if endpoint requires auth
3. responseCode = "403" (forbidden) if endpoint requires admin role
4. responseCode = "404" (not found) for get-by-id style endpoints

Use @ApiResponse(content = @Content(schema = @Schema(implementation = YourVO.class))) where YourVO is the VO/DTO type inside Result<>. Do NOT use Result.class as the schema type.
